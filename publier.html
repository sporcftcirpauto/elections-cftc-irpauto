Mot de passe de l'équipe

Choisissez le mot de passe qui permettra de publier les tracts. Il remplace immédiatement l'ancien mot de passe.

Uniquement pour l'administrateur du site. Elle est enregistrée sur le site chiffrée avec le mot de passe : sans le mot de passe, personne ne peut la lire.

12 caractères minimum. C'est la seule protection de l'espace : prenez une phrase d'au moins 4 mots, facile à retenir mais impossible à deviner (pas de nom, de date ou de « cftc2026 »).

Comment obtenir la clé d'accès GitHub ? (à faire une seule fois)
  1. Connectez-vous à GitHub avec le compte qui gère le site, puis ouvrez la page de création de clé .
  2. Token name : « Tracts CFTC ». Expiration : choisissez une date après les élections.
  3. Repository access : « Only select repositories », puis choisissez elections-cftc-irpauto.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ci-dessus.

C'est prêt. Le nouveau mot de passe est actif.

  • Pour publier : sur le site, cliquez sur le petit cadenas en haut à droite, puis entrez le mot de passe.
  • Ne donnez le mot de passe qu'aux personnes qui publient les tracts, de vive voix de préférence.
  • Pour le changer : « Changer le mot de passe » dans l'espace équipe. Tous les appareils devront se reconnecter avec le nouveau.
  • Pour retirer l'accès à quelqu'un qui connaissait l'ancien mot de passe, remplacez aussi la clé GitHub (supprimez-la sur GitHub, créez-en une nouvelle) avant de choisir le nouveau mot de passe.

    Connecter les statistiques

    Le site mesure sa fréquentation avec GoatCounter : un service gratuit, anonyme et sans cookie. Pour afficher les chiffres ici, collez une seule fois la clé d'accès GoatCounter.

    Elle est enregistrée sur le site chiffrée : seules les personnes connectées à l'espace équipe peuvent l'utiliser.

    Comment obtenir la clé GoatCounter ? (à faire une seule fois)
    1. Créez le compte sur goatcounter.com/signup  : Code : sporcftcirpauto (exactement), puis votre e-mail et un mot de passe.
    2. Dans Settings, choisissez le fuseau horaire Europe/Paris (champ Timezone) et enregistrez avec Save.
    3. Ouvrez le menu en haut à droite (votre e-mail) → API → New API key : donnez-lui un nom, cochez seulement Read statistics, puis créez la clé.
    4. Copiez la clé et collez-la ci-dessus.
