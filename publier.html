Connexion

Pour publier, collez votre clé d'accès GitHub. Elle n'est envoyée qu'à GitHub et reste enregistrée uniquement sur cet appareil.

Comment obtenir ma clé d'accès ? (à faire une seule fois)
  1. Connectez-vous à GitHub avec le compte qui gère le site, puis ouvrez la page de création de clé .
  2. Token name : « Tracts CFTC ». Expiration : choisissez une date après les élections.
  3. Repository access : « Only select repositories », puis choisissez elections-cftc-irpauto.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ci-dessus.

Ne partagez jamais cette clé : elle permet de modifier le site. En cas de doute, supprimez-la sur GitHub et créez-en une nouvelle.
